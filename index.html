User Guide & Application Documentation

Welcome to Sri Renga Vilas Finance Engine! This application provides full-fledged wealth tracking, budgeting, and analytics. Below is a complete detailed breakdown of how to use each section of the application.

1

Expense Tracker (Dashboard)

Purpose: Serves as your central financial dashboard.
How to Use:
• Live Activity Bar: View income, expenses, and net balance logged specifically for today.
• Analytics Filters: Use the filter panel at the top to filter data by timeframe (This Week, Month, Year, Custom Range) or Category/Subcategory.
• Key Metric Cards: Instantly check Net Balance, Total Income, Total Expenses, Investments, and EMI obligations.
• Charts: View visual comparisons of Income vs. Expense and category-wise donut distribution.

2

Goals & Essentials

Purpose: Track long-term financial targets (e.g., Retirement, Education) and essential protections (e.g., Insurance policies).
How to Use:
• Fill in the Add / Edit Financial Goal form with Goal Name, Saved Value, and Target Value.
• Fill in the Essential Covers form to track protection items with statuses: "Fully Covered" or "Attention Needed".
• Real-time progress bars dynamically calculate completion percentages on the main dashboard.

3

Daily Entries (Transactions)

Purpose: Log income, expenses, bank transfers, savings, and investments.
How to Use:
• Select transaction Type (Income, Expense, Transfer, Savings, Investment).
• Select Categories and dynamically populated Subcategories.
• If selecting Transfer, specify both Source Account and Destination Account.
• Switch between Table View and Grid View.
• Export all data anytime using the Export CSV or Export Excel buttons.

4

Spending Manager (Calendar)

Purpose: View daily transaction activity visually on a monthly calendar grid.
How to Use:
• Days with financial activity show visual dots (Green for Income, Red for Expense).
• Click any calendar day cell to instantly view all itemized line transactions recorded on that date.

5

Budget & Insights

Purpose: Advanced analytics for financial trajectory and expense breakdown trends.
How to Use:
• Analyze Balance & Spending Trend Velocity over time via interactive line charts.
• Review monthly expense trends by individual categories.

6

Smart Widgets

Purpose: Quick-launch dashboard for immediate actions and high-level summaries.
How to Use:
• Check instant metrics (Today's spend, Monthly surplus ratio).
• Use quick-action launch buttons to log expenses or jump directly to the calendar.

7

Monthly Summaries

Purpose: Month-by-month financial statement overview.
How to Use:
• View compiled historical monthly records displaying Total Income, Total Expenses, and Net Savings Margin per month.

8

Investment Portfolio

Purpose: Record and monitor investments across various asset classes.
How to Use:
• Log investments specifying Asset Class (Gold, Mutual Funds, Real Estate, Business, etc.), Principal Amount, and Expected Return Rate (% p.a).

9

Active EMIs & Loan Engine

Purpose: Automatic EMI calculation and debt management.
How to Use:
• Input Principal, Annual Interest Rate, Tenure (Months), and Start Date.
• The system automatically calculates monthly EMI payments using standard financial amortization formulas.

10

User Tracking & Admin Control Panel

Purpose: Track active users, view login timestamps, and manage master categories.
How to Use:
• Track online status, last login timestamps, and transaction counts of registered users.
• Review user login audit logs.
• Add or delete banks, accounts, categories, and subcategories.
